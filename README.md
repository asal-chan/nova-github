# Nova | Web Design Studio

## فارسی

Nova یک وب‌سایت فارسی برای یک استودیو طراحی و توسعه وب است.

این پروژه با یک قالب HTML مبتنی بر Bootstrap شروع شد و در ادامه، آن را به یک قالب پویا و قابل مدیریت در WordPress با استفاده از PHP تبدیل و توسعه دادم.

تمرکز اصلی این پروژه، یادگیری و پیاده‌سازی عملی توسعه WordPress بوده است، نه صرفاً استفاده از ابزارهای آماده.

### کارهایی که در پروژه انجام دادم

* تبدیل قالب HTML/Bootstrap به قالب WordPress
* ساخت `Custom Post Type` برای خدمات و نمونه‌کارها
* ساخت `Custom Taxonomy`
* طراحی و پیاده‌سازی فیلدهای سفارشی با `ACF`
* ایجاد `ACF Options Page` برای تنظیمات کلی سایت
* ساخت بلوک‌های اختصاصی با `Gutenberg` و `ACF`
* ایجاد قالب‌های پویا و اجزای قابل استفاده مجدد
* توسعه فرم تماس با PHP و `wp_mail()`
* شخصی‌سازی `WordPress Customizer`
* ایجاد مدیریت پویا برای فونت‌ها
* رفع خطا و اشکال‌زدایی در PHP و WordPress
* توسعه و آزمایش پروژه در محیط محلی و هاست
* استفاده از Git و GitHub برای مدیریت نسخه‌ها

### چیزهایی که یاد گرفتم

این پروژه تجربه عملی من در زمینه‌های زیر بود:

* توسعه WordPress با PHP
* ساخت و مدیریت `Custom Post Type` و `Taxonomy`
* طراحی ساختار محتوای سفارشی با `ACF`
* ساخت بلوک‌های اختصاصی `Gutenberg`
* کار با `Query` و `Template Hierarchy`
* کار با `Hooks` و توابع WordPress
* اشکال‌زدایی و حل مشکلات واقعی پروژه
* توسعه و مدیریت پروژه در محیط محلی و هاست
* استفاده از Git و GitHub

### تکنولوژی‌ها

`PHP` · `WordPress` · `ACF` · `Gutenberg` · `Bootstrap` · `HTML` · `CSS` · `JavaScript` · `MySQL` · `Git`

## English

Nova is a Persian website for a web design and development studio.

The project started from an HTML template built with Bootstrap. I converted and developed it into a dynamic and manageable WordPress theme using PHP.

The main focus of this project was learning and applying WordPress development rather than simply using ready-made tools.

### What I Built

* Converted an HTML/Bootstrap template into a WordPress theme
* Created `Custom Post Types` for Services and Portfolio items
* Created `Custom Taxonomies`
* Designed and implemented custom fields using `ACF`
* Created an `ACF Options Page` for site-wide settings
* Built custom `Gutenberg` blocks with `ACF`
* Developed dynamic and reusable templates
* Built a contact form using PHP and `wp_mail()`
* Customized `WordPress Customizer` settings
* Added dynamic font management
* Debugged and fixed PHP and WordPress issues
* Developed and tested the project locally and on a live host
* Used Git and GitHub for version control

### What I Learned

Through this project, I gained practical experience with:

* PHP and WordPress development
* Custom Post Types and Taxonomies
* ACF and custom content structures
* Gutenberg block development
* WordPress Query and Template Hierarchy
* WordPress Hooks and functions
* Debugging and troubleshooting
* Local and live WordPress development
* Git and GitHub

### Technologies

`PHP` · `WordPress` · `ACF` · `Gutenberg` · `Bootstrap` · `HTML` · `CSS` · `JavaScript` · `MySQL` · `Git`

### About the Project

This project helped me move beyond using WordPress as a content management system and gain hands-on experience with developing and customizing WordPress themes using PHP.
